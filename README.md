# 🏓 Classic Ping Pong Game

A simple, minimalist **Ping Pong Game** built with Python's built-in [`turtle`](https://docs.python.org/3/library/turtle.html) graphics module.

## ✨ Features

* 🏓 Classic Ping Pong gameplay
* 🎮 Keyboard controls
* Opposite style scoring system
* Speed Increment on Paddle hit
* 💥 Game-over detection
* 🐢 Built using Python's built-in `turtle` module

## 🕹️ Controls

| Key       | Action                        |
| --------- | ------------------------------|
| `w` / `s` | Move Up/Down For Left Player  |
| `↑` / `↓` | Move Up/Down For Right Player |


## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

Python **3.x** is recommended.

You can check your installed version with:

```bash
python --version
```

> **Note:** You don't need to install `turtle` separately. It is included with standard Python installations.

### 2. Clone the Repository

```bash
git clone https://github.com/vedantparikh21/Classic-Ping-Pong-Game.git
cd Classic-Ping-Pong-Game
```

### 3. Run the Game

```bash
python main.py
```

Enjoy the game! 🏓🎮
